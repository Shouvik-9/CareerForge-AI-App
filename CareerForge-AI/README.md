# CareerPilot AI

AI-powered career guidance platform built with Flask and Gemini.

## 🚀 Live Demo

[Open CareerPilot AI](https://careerpilot-ai-mmb6.onrender.com/)

## ✨ Features

- AI Interviewer
- Career Assistant
- Personalized Career Roadmap
- Resume Analysis
- AI-powered skill gap analysis
- Career roadmap PDF download
- Voice-enabled AI interaction

## 🛠 Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Gemini API
- SQLite
- ReportLab

## 📌 Project

CareerPilot AI helps users analyze their resumes, practice interviews, get personalized career guidance, and generate a career roadmap based on their target role.
